# Contributing

Issues are welcome: bug reports, errors, questions. Please say what you ran, what you expected, what you saw, and
the versions of the tools involved. Remove any keys, tokens, account names or private text first.

Pull requests are not accepted for now. The project has one maintainer and is at version 0.1; this may change in
a later version.

Security problems go through a private report, not an issue: see `SECURITY.md`.
